# Bosutinib dans le site ATP de Bcr-Abl — démonstration 3D

Page interactive pour l'exercice « interactions intermoléculaires » : le bosutinib entre dans le site de liaison de la kinase Abl (structure cristallographique **PDB 3UE4**) et les acides aminés qui l'accrochent sont mis en évidence, avec le type d'interaction à pH physiologique et les distances mesurées sur le cristal.

**➡️ Ouvrir la démonstration : https://ayoubminaei.github.io/bosutinib-3d/**

| Acide aminé | Partie | Interaction |
|---|---|---|
| Méthionine 318 | chaîne principale (N–H) | liaison hydrogène avec le N1 de la quinoléine |
| Thréonine 315 | chaîne latérale (OH) | liaison hydrogène |
| Phénylalanine 317 | chaîne latérale | empilement π–π |
| Tyrosine 320 | chaîne latérale | hydrophobe |
| Aspartate 323 | chaîne latérale (COO⁻) | ionique, avec la N-méthylpipérazine protonée |
| Alanine 380 | chaîne latérale (CH₃) | hydrophobe |
| Phénylalanine 382 | chaîne latérale | empilement π–π |

## Utilisation

- **▶** en bas : rejouer l'entrée du bosutinib ; la frise permet d'avancer ou de reculer.
- Barre d'outils : zoom, noms des acides aminés, interactions et distances, résidus voisins, surface de la poche, ruban, style du ligand, thème clair / sombre, capture PNG, plein écran.
- **?** en bas à droite : comment faire tourner, zoomer et déplacer la vue.
- Cliquer sur un acide aminé (dans la scène ou dans la liste) zoome dessus ; l'œil le cache.

Aucune installation : un navigateur récent suffit. La structure est téléchargée depuis la [Protein Data Bank](https://www.rcsb.org/structure/3UE4) à l'ouverture.

Réalisé par [Pharmakinase.com](https://pharmakinase.com) — fiches, quiz et schémas interactifs pour les études de pharmacie.
